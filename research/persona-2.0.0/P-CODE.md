## Tried, could not break

- **v5 ingress whitelist.** Loaded a v5 file carrying `projectMeta`, `sheetDone`, `viz.fillMode: "faint"` and a per-condition `patternIdx`, then read `VESApp.snapshot()` back: project name/client/address/preparedBy intact, `sheetDone {1:true}` intact, `fillMode "faint"` intact, `patternIdx` kept on all 26 conditions, 26/26 conditions survived, no drop banner. `normalizeSnapshot`'s return is a whitelist but every raw-side key is re-applied at commit.
- **Version refusal.** A file with `version` above 5 is refused by name, not guessed at.
- **`descOf` on one line across surfaces.** The same engine line printed **"Standing Seam Panel"** on the bid, the Estimate grid, the recap and the takeoff, and its labor line printed **"Standing Seam Panel — labor"** on the grid — no ad-hoc ternary and no id-shaped name reached any of them. `node tools/vocab-check.mjs src/VES_PM.html` → **0 findings**.
- **Section money grouping is case-insensitive where the money is.** Across the rename in B6C-7 the grand held at **cost $410,527.62 / sell $512,092.16** and the three bid section subtotals ($76,106.21 + $416,721.66 + $19,264.29) summed to the grand exactly. The rename moves money between sections without re-pricing a cent; only the two surfaces in B6C-7/B6C-8 disagree about where it sits.
- **Empty print returns do release the latch.** With every condition and measurement removed, both `printBidDoc()` and `printTakeoff()` leave `#printDoc` reading **"Nothing to print — use Files & exports."** — the D-24.7a returns are clean; only the *successful* path (B6C-9) is not.
- **Pitch rejects what it should.** `abc` and `-6` are both refused: stored pitch stays absent, factor 1, quantity unchanged at 3,596.9 SF, card reads "pitch: flat". `6/13` is accepted as rise 5.538 and *displayed* as "5.54/12" — the arithmetic and the display agree, so I did not count it.
- **The R-3a reconciliation IS on the undo stack, and named.** After loading `takeoff.v3.json` the stack is depth 1 with the label **"pitch reconciled on 3 conditions (file v3 → v5)"**; Ctrl+Z moves sell **$512,092.16 → $496,800.67 (−$15,291.49, the banner's own figure)** with toast "Undid: pitch reconciled on 3 conditions (file v3 → v5)", and redo restores it exactly. The reversal itself works — what it leaves behind is B6C-5 and B6C-6, and its position at the bottom of the stack is what makes B6C-1 dangerous.
- **Both migration banners raise on the fixture**, each with its own arithmetic: the reconcile banner (three conditions, three deltas, sell before → after) and the per-condition legacy confirm ("Cricket framing — pitch was stored as ×6.000 — reads as 6/12; confirm.
